This folder contains documentation that no longer matches the current code, but still has value.
- 0_MHQ New Player Guide: a lot of work went into this and I don't have the heart to delete it. Most contents have been 
moved into the in-game glossary.
- Awards Module: the guide for creating user-made award sets is still correct, the rest is outdated
- Education Module: the guide for creating user-made academies is still correct, the rest is outdated
- MegaMek -MekHQ Chaos Campaign Guide: starting in 51.01 we started officially supporting chaos campaigns and most of 
  the contents is no longer accurate. While we're still working in incorporate all chaos campaign rules, however, it's 
  still a valuable doc.
- MHQ_noble_playset: while most systems have now been included in MekHQ there are still a few ideas that could be used 
  to create a unique and interesting campaign
